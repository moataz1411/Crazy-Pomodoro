# Crazy Pomodoro

A creative and interactive Pomodoro timer built using **HTML, CSS, and JavaScript** with advanced UI effects and auto cycle productivity system.

---

**Features**

- Pomodoro Timer with 3 modes (Classic / Focus / Productive modes)
- Auto cycle between focus and break sessions
- Animated rain visual effect during focus mode
- Background **relaxing** music with mute toggle
- Dark mode support
- Fullscreen mode
---

**Modes**

- **Classic Mode** → 25 minutes 
- **Focus Mode** → 35 minutes 
- **Productive Mode** → 45 minutes 

**Break system:**

- Short Break → 5 minutes
- Long Break → 15 minutes

---

## How It Works

1. Select a mode (Classic / Focus / Productive)
2. Press **Start**
3. Timer begins and background effects activate
4. After each session:
   - App automatically switches between focus and breaks
   - Cycle system keeps track of progress
