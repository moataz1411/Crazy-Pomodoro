# Crazy Pomodoro

A interactive Pomodoro timer built using HTML, CSS, and JavaScript with beautiful UI effects and auto cycle system.

---

**Features**

- Pomodoro Timer with 3 modes 
- Auto cycle between focus and break 
- Background relaxing music to increase the focusing
- Dark mode 
---

**Modes**

- Classic Mode : 25 minutes 
- Focus Mode :35 minutes 
- Productive Mode : 45 minutes 

**Break system:**

- Short Break : 5 minutes
- Long Break : 15 minutes

---

**Setup**

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Enjoy and coding with crazy pomodoro

---

**Usage**

1. Select your preferred focus mode.
2. Press Start to begin the timer.
3. The timer will automatically switch between focus sessions and breaks.

---

**languags used**

- HTML
